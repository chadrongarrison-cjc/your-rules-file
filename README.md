# Your rules file

Claude writes like a stranger until you tell it how you work. This plugin fixes that with one file.

Run `/your-rules-file:rules-file` and Claude asks you a handful of questions, one at a time: your name, your business, what you do and for whom, the jobs you hand it most, the words you never want to see. It fills in a rules file from your answers and hands it back as a text file you can open. You paste that file into Instructions for Claude once (Settings, under Account in the desktop app or under General on claude.ai), and every chat and every Cowork task reads it from then on.

The rules in the file: write the way you talk to a customer, no em dashes and no filler words, never make up a fact or a number, ask one question at a time with choices, draft everything and send nothing without your OK, hand finished work over as a file you can open, and turn every correction into a one-line rule so you never repeat yourself.

The skill also walks you through the before-and-after test: the same job in two normal chats, one before the paste and one after, side by side.

## What this plugin does and does not do

- It reads your answers in the chat and, if you have a folder open, writes one text file into it. Nothing else is read or written.
- It sends nothing anywhere. There is no server, no connector, no hook, and no code that runs; the plugin is one skill written in plain words.
- It asks for no password, key, or account.
